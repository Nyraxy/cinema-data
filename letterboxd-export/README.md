Upload your Letterboxd export ZIP here once (Add file → Upload files).
Get it from https://letterboxd.com/user/exportdata/ — the workflow unzips it automatically and uses
watched.csv, ratings.csv and likes/films.csv for your older watched films, ratings and likes.

This is a one-time step: the data file keeps everything it has seen, and every run adds your new
watches, ratings and likes from your Letterboxd RSS feed and first films page. Only re-upload if you
change ratings of older films and want those picked up.
